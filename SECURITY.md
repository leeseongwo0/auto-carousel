# Security policy

## Reporting a vulnerability

Report suspected vulnerabilities privately through GitHub Private Vulnerability Reporting or a GitHub Security Advisory for this repository:

- [Private Vulnerability Reporting / Security Advisories](../../security/advisories/new)

Do not disclose vulnerabilities, credentials, tokens, session data, private configuration, personal data, or proof-of-concept secrets in a public issue, discussion, pull request, commit, or comment. If credentials may have been exposed, revoke or rotate them before submitting the private report and describe only the minimum necessary evidence.

Include the affected version or commit, a concise reproduction, impact, and any proposed mitigation. Reports are handled on a best-effort basis; no response or remediation timeline is guaranteed.

## Scope

The public manual/local workflow is in scope. Legacy Telegram, Google Sheets, Asia/Seoul scheduling, systemd, and Codex compatibility adapters may be reported when they are present in this repository. Third-party services and user-managed deployments remain subject to their own security processes.
