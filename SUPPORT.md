# Support

For public usage questions, installation help, and reproducible bugs, use this repository's [GitHub Issues](../../issues) or [GitHub Discussions](../../discussions).

Please include the Newsbot version or commit, operating system, the manual command you ran, redacted output, and the smallest reproducible example. Never include credentials, tokens, private configuration, personally identifiable information, or production data.

Support is provided by a single maintainer on a best-effort basis. There is no SLA, guaranteed response time, or personal-email support channel.

For security-sensitive reports, use the private process in [SECURITY.md](SECURITY.md), not Issues or Discussions.
